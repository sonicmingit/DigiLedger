# 外接搜图服务申请与配置手册

在“系统设置 → 外接 API”中启用服务后，物品封面搜图会使用该服务。密钥仅保存于数据库，页面不会回显明文。

## 京东联盟商品搜索

1. 访问 [京东联盟开放平台](https://union.jd.com/openplatform/api) 注册推广者或媒体账号，并完成主体审核。
2. 在联盟后台创建应用，获取 `AppKey` 与 `AppSecret`，再创建推广位并记录联盟 ID / 推广位 ID。
3. 设置服务地址为 `https://api.jd.com/routerjson`，API Key 填写 `AppSecret`。
4. 扩展配置 JSON 填入：`{"appKey":"你的AppKey","unionId":"你的联盟ID","siteId":"可选推广位ID"}`。
5. 启用后使用“品牌 + 型号”进行测试。平台权限、联盟资质和商品推广范围由京东联盟决定。

## 淘宝联盟商品搜索

1. 注册 [淘宝开放平台](https://developer.alibaba.com/) 与淘宝联盟推广者账号。
2. 创建应用并申请 `taobao.tbk.dg.material.optional` 权限，获取 `AppKey`、`AppSecret` 和推广位 `adzoneId`。
3. 设置服务地址为 `https://eco.taobao.com/router/rest`，API Key 填写 `AppSecret`。
4. 扩展配置 JSON 填入：`{"appKey":"你的AppKey","adzoneId":"你的推广位ID"}`。
5. 启用后测试关键词搜索。该接口可返回商品主图 `pict_url`。

## Icecat 产品目录

1. 访问 [Icecat](https://icecat.com/) 注册 Open Icecat 或商业账号；数码、IT、办公设备覆盖较好。
2. 设置服务地址为 `https://live.icecat.biz/api`，API Key 填写 Icecat 用户名或访问令牌（以账号方案为准）。
3. 扩展配置 JSON 可填 `{"language":"zh"}`。
4. 用“品牌 + 型号”测试，例如 `Sony A7C`。Icecat 以官方规格/产品图为主，不保证覆盖全部型号。

## Brave Image Search

1. 访问 [Brave Search API](https://api-dashboard.search.brave.com/) 注册并创建订阅 Token。
2. 设置服务地址为 `https://api.search.brave.com/res/v1/images/search`，API Key 填写 `X-Subscription-Token`。
3. 扩展配置 JSON 示例：`{"country":"CN","searchLang":"zh-hans","safeSearch":"strict"}`。
4. 启用后测试关键词。建议将它作为商品目录无法命中时的通用兜底，并由用户选择最终封面。

## SerpApi Google 商品图片搜索（推荐）

1. 访问 [SerpApi](https://serpapi.com/) 注册账号并创建 API Key；该服务负责从 Google 图片搜索获取结构化结果，无需自行处理验证码或页面结构变化。
2. 设置服务地址为 `https://serpapi.com/search.json`，API Key 填写 SerpApi API Key。
3. 扩展配置 JSON 示例：`{"domains":["jd.com","taobao.com","tmall.com"],"gl":"cn","hl":"zh-CN"}`。
4. `domains` 是允许返回的来源页域名。后端会同时在搜索词中加入 `site:` 条件，并再次按返回页域名过滤；可改成品牌官网域名以搜索官方产品图。
5. 保存、启用后，到“系统设置 → 搜图配置”勾选此服务。

## 注意事项

- 旧的网页解析型京东/淘宝搜图和百度网页搜图已弃用：其上游会忽略站点限定、缺失缩略图或触发风控，不能保证结果正确。
- Google 官方 Custom Search JSON API 已关闭新客户接入；此处的 Google 商品图片搜索使用的是 SerpApi 代理服务，不是 Google 官方 CSE。
- 各平台的审核、额度、推广合规和图片版权由对应平台规则约束。
- 已执行过的 Flyway 迁移不得手动修改；生产环境新增默认连接器应新增下一版本迁移。
