# H5 主备服务复现检查

主备地址保存在设备本地，不进入后端偏好接口。可在 H5 设置页按以下矩阵复现
`src/services/http.ts` 的切换规则。

| 场景 | 主节点 | 备用节点 | 预期结果 |
| --- | --- | --- | --- |
| 幂等读取断网或超时 | 不可达 | 可用 | GET/HEAD 在备用节点重试一次 |
| 幂等读取 5xx | 返回 500 | 可用 | GET/HEAD 在备用节点重试一次 |
| 客户端错误 | 返回 4xx | 可用 | 直接显示错误，不访问备用节点 |
| 业务错误 | HTTP 200，`code != 200` | 可用 | 直接显示业务错误，不访问备用节点 |
| 写请求失败 | POST/PUT/PATCH/DELETE 不可达或 5xx | 可用 | 不访问备用节点，不自动重放 |
| 独立连接测试 | 指定任一节点 | 另一节点可用 | 只测试指定节点，不触发切换 |

复现时可在浏览器 Network 面板确认请求次数和目标 URL。Android 真机应将主、备用
地址配置为设备可访问的完整 HTTP/HTTPS 地址，不能使用 H5 同源默认值 `/api`。
